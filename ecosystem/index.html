Questions

What does the ilang-ai GitHub organization publish?

The iLang protocol, the tools that load and measure it, and the research built on it. The newest are ilang-judge (the v5.0 judgment layer as a service, with a daily public stream of production decisions), the iLang loader (pip and npm ilang-protocol), the canon with its runtime bundles, ilang-conformance with 45 scored model runs, Agent Ready GEO and research.ilang.ai. All sixteen repositories are MIT licensed and archived on Zenodo with DOIs.

What is the iLang loader?

A small Python and JavaScript package, ilang-protocol, that fetches the official iLang runtime, checks its sha256, caches it and adds it to every model request, for any model. People do not need to learn iLang; the loader gives it to the AI.

What is ilang-conformance?

A deterministic test set for the iLang protocol: 320 cases across grammar, execution and judgment. Code scores any model reachable over an API; no model grades another. 45 runs are published, and none reached the L1 gate.

What is ilang-judge?

The iLang v5.0 judgment layer as a service. One stateless endpoint asks a second judge eleven three-level rubric questions, one per dimension, anchored on the canon's own definitions, computes the eleven-dimension vector, runs f_v5 from the pinned canon validator and writes the deciding step in code. Observer plugins call it from Hermes and LangBot bots without changing their behaviour, and an exporter publishes the decisions daily as a public Hugging Face dataset, with identifiers pseudonymised and no conversation text.

What is Agent Ready GEO?

An agent skill for Claude Code, Codex and other clients that load Agent Skills. It takes a website to 100/100 on isitagentready.com, and its instructions are written in iLang.
