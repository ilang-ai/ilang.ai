## Lernen Sie iLang nicht. Ihre KI sollte es.

iLang ist ein Protokoll für KI, keine Sprache, die Menschen auswendig lernen müssen. Sie sagen weiter in eigenen Worten, was Sie wollen; Ihre KI lädt iLang und arbeitet danach.

- **Im Chat:** Kopieren Sie die [aktuelle iLang-Laufzeit](https://raw.githubusercontent.com/ilang-ai/ilang-spec/main/runtime/ilang-latest.md) oder drücken Sie auf [ilang.ai](https://ilang.ai) „Copy latest iLang“ und fügen Sie sie in ChatGPT, Claude, Gemini, DeepSeek, Qwen oder einen anderen Assistenten ein.
- **Im Code:** `pip install ilang-protocol` oder `npm install ilang-protocol`, dann `messages = ilang.wrap(messages)`. Der [Loader](https://github.com/ilang-ai/ilang) holt die offizielle Laufzeit, prüft sie und fügt sie jeder Anfrage hinzu.

Alles Weitere richtet sich an KI, Entwickler, Forschende und alle, die das Protokoll prüfen.

---

So wie HTTP die Webkommunikation und SQL Datenbankabfragen standardisiert hat, **standardisiert iLang die Kommunikation zwischen Mensch und KI**. Ein offenes Protokoll, getestet mit ChatGPT, Claude, Gemini, DeepSeek, Kimi, Qwen und GLM.

## Was iLang kann

| Fähigkeit | Beschreibung |
|-----------|-------------|
| **Komprimieren** | Prompts um 7% bis 68% reduzieren. Weniger Tokens |
| **Alles beantworten** | KI antwortet direkt und vollständig, ohne Disclaimers |
| **Privatsphäre schützen** | Komprimierter Text sendet weniger Daten |
| **Plattformübergreifend** | Eine Anweisung, getestet mit ChatGPT, Claude, Gemini, DeepSeek, Kimi, Qwen und GLM |
| **Kettenbefehle** | `[VERB]=>[VERB]=>[OUT]` Mehrstufige Workflows in einer Zeile |

## In 30 Sekunden starten

Kopieren Sie den Protokoll-Header von [ilang.ai](https://ilang.ai) und fügen Sie ihn in eine beliebige KI-Konversation ein.
