Don’t learn iLang.
Your AI should.

iLang is a protocol for AI, not a language for people to memorise. You keep saying what you want in your own words: your goals, your conditions, what may and may not be done. Your AI loads iLang, reads it, writes it and works by it.

How do I use iLang?

I chat with ChatGPT, Claude, Gemini, DeepSeek or Qwen

Copy the latest iLang and paste it into your AI. No reading, no syntax, nothing to learn.

I want my AI to load it every time

Install the loader. It fetches the official runtime, checks it and adds it to every request.

pip install ilang-protocol
npm install ilang-protocol
messages = ilang.wrap(messages)

Or connect the MCP server once: https://ilang.ai/mcp

claude mcp add --transport http ilang https://ilang.ai/mcp

Loader on GitHub · Add to Cursor · Claude and ChatGPT: add the URL as a connector

Evidence

Measured, not assumed.

Every number here comes with its code and data under a DOI. We ask readers not to trust our numbers but to re-run them.

45 model runs, 320 cases each, scored by deterministic code and the canon’s own validators. No model grades another. Conformance results → 80% vs 9% median pass rate on grammar cases against execution cases, across the 34 comparable runs. Form is attainable; action is not. Preprint → 68.4% → 80.9% agreement between the judge and the reference on an unbiased random sample, over three days in production. Production audit →
